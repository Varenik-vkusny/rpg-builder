- [x] Автор видит «было → стало» по каждому полю и результат проверки плана на копии | flutter test --no-pub test/plan_copy_test.dart --name "копия"
- [x] Ассистент сам исправляет план по ошибкам проверки, не больше двух раз; дальше «Применить» недоступно | flutter test --no-pub test/autofix_test.dart --name "исправлени" && bash scripts/fn-test.sh "исправлени"
- Автор применяет план — всё пишется одной транзакцией или не пишется ничего
- Автор отклоняет план — в базе ничего не меняется
- Автор видит историю наборов изменений и откатывает любой
- Автор просит ассистента исправить проблему прямо с экрана «Проверка мира»
- Сцена «штольня» проходит вживую: 6 изменений, урон 14 пойман и исправлен на 8, применить, откатить

## 4. Польза сверху ядра

- Автор меняет и удаляет локации, предметы, персонажей, квесты вручную (удаление со ссылками — ошибка)
- Автор видит обзор мира: счётчики по типам, сводка проверки, последние изменения
- Автор фильтрует предметы по редкости и типу, персонажей по роли
- Автор фотографирует скетч, ассистент предлагает карточку персонажа
- Автор экспортирует мир в JSON под `JsonUtility` и отправляет через «Поделиться»; перед экспортом мир проверяется
- Автор ищет образцы в Open5e и импортирует их с атрибуцией

## 5. Карта

- Автор видит схему мира: локации, кто где живёт, какой квест куда ведёт
- Автор задаёт переходы между локациями, ассистент правит и их
- Автор ставит локации метками на фото или скетч карты

## 6. Если успеваем

- Автор надиктовывает просьбу ассистенту голосом
- Автор заказывает пачку объектов: тип, количество, уровни, редкость
- Сцена в Unity читает экспортированный JSON

## 7. В конец — края и красота

- Знакомство из трёх слайдов при первом запуске
- Профиль: язык ассистента, счётчик токенов, выход
- Ошибка сети при запросе к ассистенту — понятное сообщение, план не теряется
