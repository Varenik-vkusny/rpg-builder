уровни) и видит его в списке своих миров. Чужих миров не видит (RLS в Supabase).
Статус: закрыт — принят владельцем 24.09.2026, ревью НОРМА, закоммичен.

## Приёмка текущего среза
```
bash scripts/check.sh
bash scripts/features.sh --force
```
Руками: `flutter run -d chrome` → регистрация → «Пепельные копи» в списке → выйти →
второй аккаунт его не видит.
