# Как мир из RPG Builder попадает в игру на Unity

Пример читает файл, который приложение отдаёт через «Поделиться → Экспорт». Что проверено: тест приложения (test/unity_example_test.dart) сверяет классы C# с форматом экспорта — поля, их вид и версию; скрипт компилируется против сборок UnityEngine 2022.3. В самом Unity (шаги 2–3) пример пока не запускался.

1. Положите `RpgBuilderWorld.cs` и `pepelnye_kopi.json` (или свой экспорт) в папку `Assets` проекта Unity.
2. В сцене создайте пустой объект и повесьте на него компонент `RpgBuilderWorldLoader`. Перетащите файл мира в поле **World Json**.
3. Нажмите Play. Слева вверху появится список: места, враги, квесты; тот же текст — в Console.

Если версия формата в файле не совпадает с `ExpectedSchemaVersion` в скрипте, вместо списка будет понятное сообщение.

Образец `pepelnye_kopi.json` — 40 объектов («Пепельные копи»): 7 мест, 10 предметов, 18 персонажей (12 врагов), 4 события, 1 квест.
